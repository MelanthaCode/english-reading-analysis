# 试卷分析细则

一篇带题目的文章，按 **题目 → 答案 → 对错分析** 三段处理；没有的部分跳过。

## 1. 每篇的结构

```
## 文章 N：<主题>
（逐段 原文 + 译文，长难句高亮 ①②③）
### 题目 · 选项 · 答案   <题号范围>
（每题一块：题干中英 → 选项中英 → 答案+题型+定位解析）
### 作答对错分析   <题号范围>
（仅在提供作答时：逐题对错 + 错因 + 纠正提示 + 汇总结论）
### 长难句拆解   ①–④
（每句一张卡片）
```

- 多篇逐篇成套，不要把不同文章的题目或句子合并。
- 编号跨篇连续，题号沿用原卷编号，便于与原卷对照。

## 2. 题块字段

| 字段 | 要求 |
|---|---|
| 题号 | 沿用原卷编号 |
| 题干 | 英文原文，不改写；下一行中文译文 |
| 题型 | 细节/推断/词义/指代/主旨标题/态度/目的，标在译文后括号内 |
| 选项 | A–D 英文 + 中文释义；长选项单列，短选项两列 |
| 答案 | `答案 X. 选项文字`；无官方答案时注明"依据原文推导" |
| 解析 | 先给原文定位句，再讲对项依据与错项错因，2–4 句 |

## 3. 题型与解法

- **细节题**：回原文找同义改写；警惕范围扩大或缩小。
- **词义猜测**：只读该词所在句与前后一句，用定义线索、举例、对比、因果推。
- **指代题**：向前找最近且单复数、逻辑都成立的先行词。
- **推断题**：须有原文依据，但答案是"没直说"的那一步；不能选原文原句复述。
- **态度题**：抓评价性形容词、转折词、让步结构；作者常先让步后表态。
- **主旨/标题题**：看首段主张 + 尾段结论 + 全文高频词；标题要覆盖"对象 + 态度/结论"。

## 4. 干扰项套路

| 套路 | 长相 | 识破方法 |
|---|---|---|
| 张冠李戴 | 把 B 的观点安到 A 头上 | 看清每句话的说话人 |
| 无中生有 | 原文没提的比较、因果、目的 | 逐字回查是否有该信息 |
| 反向 | 把"容易"说成"抗拒"、把"支持"说成"漠不关心" | 注意 prone/resistant、supportive/unconcerned 这类反义对 |
| 以偏概全 | 拿让步段的旧观点当全文主旨 | 看作者最终站哪边 |
| 偷换范围 | all/only/must 等绝对词 | 核对原文限定词 |
| 过度推断 | 合理但原文没给 | 只选有定位句支撑的 |

## 5. 对错分析

只在拿到作答信息时做：

1. **逐题表**：题号 / 作答 / 参考答案 / 对错。
2. **错因归类**（每错题只归一个主因）：
   - 定位错误：找错段落或句子；
   - 词义误判：按单词表印象选，未看上下文；
   - 主旨偏差：选了局部细节或作者反驳的观点；
   - 过度推断：选项合理但原文无据；
   - 态度误读：把让步当主张、把客观陈述当评价；
   - 范围偷换：忽略 all/only/must 等限定。
3. **纠正提示**：一句，指回原文位置。
4. **小结**：正确率 + 集中失分题型 + 下一步看哪几段。

手写答案若靠笔迹辨认，注明"按笔迹辨认，仅供对照"。

## 6. 例（词义题的最小样例）

> 41. What does the word "nuances" underlined in Paragraph 2 most probably mean?
> 第二段划线词 nuances 最可能是什么意思？（词义猜测）
> A 重大成就　B 复杂情绪　C 重大影响　D 细微差别
> 答案 D. Fine differences
> 解析：上文 `repeat received wisdom without exploring the nuances`，下文 `What I wish I taught my daughter earlier are these nuances`，都指"比较也分好坏、要看你怎么看"这类细微区别；A、C 与"比较"语境无关，B 只是把 compare 与 feeling 硬扯在一起。

要点：词义题答案必须能放回原句读通，而不是只靠词形联想。
